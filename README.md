The file game.py can be run on terminal itself. It includes multiple games such as Cricket simulators, Cricket and Football.
Cricket game includes tournament modes with real fixtures such as T20 WC 2024, 2003 ODI WC, 2023 IPL, 2023 ODI WC.
Football includes tournament mode as well with real fixtures such as UCL 2023-24, 2022 FIFA WC, Euros 2024, EPL 2024-25, 2026 FIFA WC Qualifiers + World Cup.

The file disgame.py contains the code for my discord bot which runs the cricket game from game.py and has a few additional games such as 
cricketers, footballers atlas.
